## 실제 답변 평가 실행안 — 서버 종료 후

프로젝트의 정상 가상환경에서 실행하며 의존성/모델을 임의로 경량화하지 않습니다.

```bash
python scripts/eval_rag.py --check-only
python scripts/eval_rag.py --name kim_eval40_qwen_literal
python scripts/eval_rag.py --name kim_eval40_qwen_normalized --scoring normalized --criteria eval/rag_eval_criteria.json
```

두 번째와 세 번째는 각각 모델 답변을 새로 생성합니다. 실행 시간이 부담되면 literal 결과의 저장 답변을 동일한 judge로 재채점해 비교할 수 있지만 생성 조건과 채점 조건을 구분해서 기록해야 합니다. normalized/강화 기준 점수를 기존 literal과 동일 기준의 개선 수치로 비교하지 않습니다.

검색만 확인할 때:
```bash
python scripts/eval_rag.py --retrieval-only --name kim_eval40_retrieval
```

결과를 `정답 n/24 · 거절 n/16 · 지어낸 답 n`으로 기록하고, 신규12답변/8거절도 분리합니다. 문장 의미·조건 누락·잘못된 출처는 원문과 직접 대조합니다.
