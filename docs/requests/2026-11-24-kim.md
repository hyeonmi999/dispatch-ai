## R-1 / 이슈 #28 — 외부 전송 정책 결정

**정책: 내부·제한 문서는 외부로 보내지 않습니다.** 공개 문서에 대한 명시적인 OpenAI 선택은 유지합니다. 사용자에게 권한이 있다는 사실과 외부 전송 허용은 별개의 조건입니다.

- 답변 생성: 검색에서 선택한 근거 중 공개가 아닌 문서가 있으면 OpenAI를 호출하지 않고, 외부 호출 없이 해당 역할이 볼 수 있는 근거 조항만 반환합니다. 로컬 모델을 자동으로 추가 로드하지 않습니다(PC 메모리 부담). 기존 note 필드로 이유를 알리는 방향을 제안하며 새 응답 필드는 요구하지 않습니다.
- 임베딩: 색인 대상에 내부·제한 문서가 하나라도 있으면 `embedding="openai"`의 색인 생성과 질문 검색을 외부 요청 전에 거부합니다. 비활성 문서도 현재 색인에 포함되므로 검사에 포함합니다. BGE 사용을 안내합니다.
- 등급 변경 뒤에도 기존 색인을 재사용할 수 있으므로, 저장된 metadata만 믿지 말고 최신 운영 목록을 검사해야 합니다. 알 수 없는 등급도 전송 허용으로 처리하지 않습니다.
- 외부 요청 실패 후 대처가 아니라 **요청 전 차단**이어야 합니다. 이전에 전송된 내용의 회수까지 보장한다는 뜻은 아닙니다.

**구현 상태:** 이 문서는 정책 결정과 구현 요청안입니다. 외부 전송 차단 코드는 아직 적용하지 않았습니다. 이슈 #28에서 정훈님이 맡겠다고 한 rag.py 변경과 중복되지 않게 분리했습니다. GitHub 댓글은 아직 게시하지 않았습니다.

**정훈님 구현 시 확인할 항목**
- [ ] staff/admin + 내부/제한 근거 + OpenAI 답변: 외부 호출 0회, 근거 조항 반환
- [ ] 전체 공개 자료 + 명시적 OpenAI 선택: 기존 동작 유지
- [ ] 내부·제한·비활성 자료가 포함된 OpenAI 색인 생성: 외부 호출 전 거부
- [ ] 공개→내부 등급 변경 후 기존 OpenAI 색인이 있어도 질문 임베딩 호출 전 거부

## R-6 — 팀 합의가 필요한 제안

답변 평가 버튼은 찬성 제안이지만 기존 DB 변경과 연결되므로 팀 동의 전에는 구현하지 않습니다. 사용자 요청 없이 API·DB를 추가하지 않았습니다.
